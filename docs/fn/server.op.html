server.op() / deop()

server.op(name) server.deop(name)

Changes a player's operator status.

Parameters

NameTypeDescription
namestringPlayer name.

Returns

Nothing.

Example

command('makeadmin', { op = true }, function(sender, args)
  if not args[1] then return false end
  server.op(args[1])
  sender:send("Granted operator status to " .. args[1])
  return true
end)
