p:send()

p:send(text)

Sends a chat message to the player. You can use color.* codes or color.translate().

Parameters

NameTypeDescription
textstringMessage text. Color codes like color.green work.

Example

on('join', function(e)
  e.player:send(color.green .. 'Welcome back, ' .. e.player.name .. '!')
end)

command('ping', function(sender)
  sender:send(color.aqua .. 'Pong!')
end)

Notes

If the player is offline, p:send does nothing. In delayed code, check p:online() first.
