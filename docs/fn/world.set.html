world.set()

world.set(x, y, z, blockId [, metadata])

Changes a block at the given overworld coordinates.

Parameters

NameTypeDescription
x, y, znumberBlock coordinates.
blockIdnumberThe new block ID. Use 0 for air.
metadatanumber, optionalOptional block data value.

Returns

A boolean indicating success.

Example

local x, y, z = world.spawn()
local success = world.set(x, y + 5, z, 89) -- places a glowstone block

if success then
  log('Block placed successfully')
end

Notes

Unknown block IDs raise a Lua error. Use 0 for air. Large edits should be divided across scheduled callbacks to avoid long ticks.
