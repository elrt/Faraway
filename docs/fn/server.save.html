Save, backup and tick helpers

server.save() server.backup() server.ticks()

server.save()

Requests a full server save. Returns nothing.

server.backup()

Starts an incremental backup. Returns a boolean indicating whether the backup started.

server.ticks()

Returns the Farkit server tick counter as a number.

Example

command("plugin-save", { op = true }, function(sender)
  server.save()
  sender:send("Save requested at tick " .. server.ticks())
  return true
end)

Notes

server.save() and server.backup() trigger server-wide operations. Restrict player-triggered commands appropriately.
