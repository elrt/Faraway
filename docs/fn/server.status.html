Ban and mute status

server.isBanned(name) server.isMuted(name)

Check whether a named player is currently banned or muted.

Parameters

NameTypeDescription
namestringPlayer name.

Returns

Both functions return false when there is no active ban or mute, or true, secondsRemaining when one is active. The remaining duration is in seconds. A permanent ban returns true, 0.

Example

local banned, seconds = server.isBanned("Alex")
if banned then
  log("Alex is banned; seconds remaining:", seconds)
end

local muted, muteSeconds = server.isMuted("Alex")
