on()

on(eventName, handler)

Subscribes a function to an event. You can register several handlers for the same event; they run in registration order. For every built-in event, its fields, trigger, and cancellation behavior are listed in the event reference.

Parameters

NameTypeDescription
eventNamestringCase-sensitive event name. See the complete event reference. Plugins may also listen for custom events sent with emit().
handlerfunctionCalled as function(e). Cancellable events may be cancelled with e:cancel([reason]).

Example

on('join', function(e)
  e.player:send('Welcome, ' .. e.player.name .. '!')
end)

on('chat', function(e)
  if e.message == 'spam' then
    e.player:send('No spam.')
    e:cancel()
  end
end)

Format chat with colors

Use color.* or color.translate() inside the chat event. This changes the message body while leaving the default player-name prefix unchanged.

on('chat', function(e)
  e.message = color.green .. e.message
end)

For a custom name and full-line format, translate a plugin-generated prefix, cancel the original chat, and send a replacement with server.broadcast(). See Chat colors.

Notes

Callbacks run synchronously on the server thread; keep them short. Cancellation is shared by all listeners, but does not stop later listeners from running. Only events documented as cancellable use that flag to affect a game operation.
