Built-in events

Register listeners with on(name, handler). This reference describes all built-in events in Farkit 1.6. Event names are case-sensitive.

Every event table starts with cancelled and cancel(reason). Cancellation only affects the operation when the row says it is cancellable. It is shared between listeners and does not stop the remaining listeners from running.

Plugin lifecycle

EventWhen it fires, fields, and behavior
readyAfter the initial plugin load, all enabled plugins receive it; a plugin loaded or reloaded later receives its own ready. Common event fields only. Informational; cancellation is ignored.
disableSent only to the plugin being disabled, before its save() hook and cleanup. Runs on unload, reload, and server shutdown. Common event fields only; cancellation is ignored.
pluginLoadedSent to other enabled plugins when a plugin is added or reloaded. Fields: name (the plugin name). Not sent for the initial startup batch. Informational.
pluginUnloadedSent to the remaining enabled plugins when a plugin is removed, reloaded, or unloaded as part of a full reload/shutdown. Fields: name. Informational.

Player events

EventWhen it fires, fields, and behavior
loginBefore a connection is admitted. Fields: name, ip. Cancellable: call e:cancel("reason") to reject the login; the reason is shown to the player.
joinAfter the player joins. Fields: player, firstJoin (boolean). Informational.
quitWhen a player leaves. Fields: player. Informational.
chatFor an allowed chat message. Fields: player, message. Set e.message to rewrite the body, or cancel to suppress it. Muted/blocked chat is stopped before this event.
commandWhen a player enters a slash command, before plugin and built-in command dispatch. Fields: player, command (the original line, including /). Cancel to consume the command.
moveWhen the player crosses into a different block coordinate. Fields: player, fromX, fromY, fromZ, x, y, z (world-space positions). Cancel to reject the move and return the player to the previous position.
damageWhen a living entity takes damage. Fields: entity, player when the target is a server player, attacker (may be nil), cause, amount. Cancel to prevent damage, or set e.amount to change it. Common causes include player, mob, other, and plugin.
deathWhen a living entity would die. Fields: entity, player when applicable, killer (may be nil), cause, health. Cancel to prevent death; the entity is revived with at least 1 health, using e.health if set.
respawnWhen a player respawns. Fields: player, x, y, z. Change one or more coordinates to redirect the respawn. Cancellation is ignored.

World and block events

EventWhen it fires, fields, and behavior
breakBefore a player breaks a block. Fields: player, x, y, z, block (block ID), meta. Cancel to prevent the break.
interactBefore a player activates a block. Fields: player, x, y, z, block (block ID). Cancel to prevent the interaction.
placeBefore a player places a block. Fields: player, x, y, z (target block after applying the clicked face), block, item (both are the placed item/block ID). Cancel to prevent placement.
explodeBefore an explosion is applied. Fields: x, y, z, power, source (entity wrapper or nil), sourceType, breakBlocks. Cancel to stop the explosion. Change power to adjust it or set breakBlocks = false to preserve blocks; entity damage still applies.
signWhen a player edits a sign. Fields: player, x, y, z, lines (Lua array indexed 1–4). Change lines to rewrite text (each line is limited to 15 characters), or cancel to reject the edit.
mobSpawnWhen a non-player living entity is about to join the world, including natural and plugin-requested spawns. Fields: entity, type, x, y, z. Cancel to prevent the spawn.

Custom events

Any plugin can dispatch a custom event with emit(name, data). Listeners receive a copy of data, with source set to the emitting plugin's name. The call returns cancelled, event; cancellation is meaningful to the code that called emit(), not to the game server.

Example

on("damage", function(e)
  if e.player then
    log(e.player.name .. " took " .. e.amount .. " damage from " .. e.cause)
  end
end)

on("explode", function(e)
  if e.sourceType == "plugin" then
    e.breakBlocks = false
  end
end)
Event listeners run synchronously on the server thread. Avoid network waits, long loops, and expensive world scans inside a handler.
