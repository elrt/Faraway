playerData()

playerData(playerOrName)

Returns a per-player table stored under <plugin folder>/players/.

Parameters

NameTypeDescription
playerOrNamestring | tableThe player's name or player wrapper object.

Returns

A persistent Lua table for the specified player.

Example

local stats = playerData("Alex")
stats.visits = (stats.visits or 0) + 1

Notes

Only serializable Lua values are persisted: tables with string/number keys, strings, numbers, and booleans. Functions, Java objects, and cyclic tables are not persisted.
