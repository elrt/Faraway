p:give()

p:give(itemId [, count])

Sends valid item stacks to an online player. Counts above 64 are split into stacks of at most 64.

Parameters

NameTypeDescription
itemIdnumberThe item ID to give.
countnumber, optionalThe amount of the item. Defaults to 1.

Returns

Nothing.

Example

command('kit', { op = true }, function(sender)
  if not sender.isPlayer then return true end

  sender:give(278, 1) -- diamond pickaxe
  sender:give(1, 64)  -- 64 stone
  sender:send("Here is your kit.")
  return true
end)

Notes

Item IDs must be greater than zero and refer to a registered item. An unknown ID raises a Lua error. Non-positive counts do not send any stacks.
