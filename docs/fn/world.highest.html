world.highest()

world.highest(x, z)

Returns the world's height-map value for the given X and Z block coordinates.

Parameters

NameTypeDescription
x, znumberWorld X and Z coordinates.

Returns

An integer height value.

Example

local x, z = 100, 100
local y = world.highest(x, z)
log("Surface at 100,100 is at Y=" .. y)
