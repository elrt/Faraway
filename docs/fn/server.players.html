server.players()

Returns an array of all currently online players.

Parameters

None.

Returns

A sequential Lua table (array) of player wrappers.

Example

local count = 0
for _, p in ipairs(server.players()) do
  p:send(color.yellow .. "Server is restarting soon!")
  count = count + 1
end
log("Warned " .. count .. " players.")
