exports

exports.key = function(...) end

Each plugin receives an initially empty Lua table in which it can publish values or functions for other plugins.

Parameters

This is a table, not a function; it has no parameters.

Returns

The plugin's own mutable exports table.

Example

-- In Clock.lua:
exports.getCount = function()
  return data.count or 0
end

Notes

Other plugins read these values through the read-only proxy returned by getPlugin(name). Assign functions during plugin load; a proxy lookup follows plugin reloads.
