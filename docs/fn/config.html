config()

config(defaults)

Reads or creates <plugin folder>/config.lua.

Parameters

NameTypeDescription
defaultstableDefault key-value configuration pairs.

Returns

A configuration table.

Example

local cfg = config({ interval = 1200, message = "Hello" })
log(cfg.message)

Notes

Missing default keys are added. Config edits are read on reload; the generated file asks for reload/restart after manual edits.
