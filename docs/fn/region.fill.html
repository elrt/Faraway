region:fill()

region:fill(blockId [, metadata])

Fills the entire region with a specified block using the extended world fill helper.

Parameters

NameTypeDescription
blockIdnumberThe block ID to place. Use 0 for air.
metadatanumber, optionalOptional block data value.

Returns

The number of block positions successfully changed, passed through from world.fill().

Example

command('cleararena', { op = true }, function(sender)
  local changed = arenaRegion:fill(0) -- clear with air
  sender:send("Cleared " .. changed .. " blocks.")
  return true
end)
