world.fill()

world.fill(x1, y1, z1, x2, y2, z2, blockId [, metadata])

Fills an area with a specific block. This is an area-limited extended block helper.

Parameters

NameTypeDescription
x1, y1, z1numberStarting coordinates.
x2, y2, z2numberEnding coordinates.
blockIdnumberThe block ID to place. Use 0 for air.
metadatanumber, optionalOptional block data value.

Returns

The number of block positions successfully changed. Returns 0 if no blocks changed.

Example

local x, y, z = world.spawn()
world.fill(x - 2, y, z - 2, x + 2, y, z + 2, 1) -- 5x5 stone platform

Notes

This helper belongs to the bundled Faraway 1.2 extension, not the base methods declared in Farkit.java. Y coordinates are clipped to 0..127; each call is limited to 131,072 block positions and larger areas raise an error. Split large edits across scheduled callbacks to avoid long ticks.
